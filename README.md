# Импульс — прототип iGaming-продукта

Учебный прототип для аудитории 18–26: ставки, рынки предсказаний и казино в одной ленте по модели TikTok.

- **[Разбор механик](https://cosmiksoul.github.io/igaming-impulse/)** — 12 модулей: гипотеза, рисерч, живое демо, метрики и подводные камни.
- **[Живой прототип](https://cosmiksoul.github.io/igaming-impulse/prototype.html)** — кликабельное демо в отдельной вкладке.

Все данные фейковые, баланс демонстрационный. 18+.
